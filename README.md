# LocaTrack_Site

The privacy & support website for **LocaTrack** (Doug's parts-inventory app for
small electrical contractors, iPhone/iPad, iCloud-synced), served via
**GitHub Pages** from `docs/`.

- Live URL (once Pages is enabled): <https://lefty3030.github.io/LocaTrack_Site/>
- Companion app repo: [Lefty3030/LocaTrack](https://github.com/Lefty3030/LocaTrack)
- Modelled on [MedTrack_Site](https://github.com/Lefty3030/MedTrack_Site) and
  [SkillTrack_Site](https://github.com/Lefty3030/SkillTrack_Site).

This URL is the App Store **Support URL** for LocaTrack, and doubles as the
privacy policy page.
